Trabajo práctico de la materia **Sistemas Operativos** cuyo objetivo es la implementación de un simulador de Sistema Operativo distribuido, desarrollado en **C**.

El sistema está compuesto por múltiples módulos independientes (Kernel, CPU, Memoria + SWAP e IO) que se comunican entre sí mediante sockets, simulando el funcionamiento interno de un sistema operativo real.
